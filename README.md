# Knufforia

Knuffiges Anime-Fantasy Idle-Spiel (Arbeitstitel). Version 1 — Auto-Kampf, Upgrades, AFK-Gold.

## Spielen

1. Repo auf GitHub öffnen
2. **Settings → Pages → Source: Deploy from a branch → Branch: `main` → Folder: `/ (root)` → Save**
3. Nach 1–2 Minuten öffnen: `https://DEIN-USERNAME.github.io/knufforia/`
4. Auf dem iPhone in Safari: Teilen → **Zum Home-Bildschirm**

## Lokal testen

```bash
cd knufforia
python3 -m http.server 8765
```

Dann im Browser: `http://localhost:8765`

## Technik

- Reines HTML / CSS / JavaScript
- Speichern im Browser (`localStorage`)
- Kein Backend nötig
